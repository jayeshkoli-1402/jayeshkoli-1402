### Natural Language Processing Project

Learned **NLP, text classification, Naive Bayes, and model evaluation** while building a News Article Classifier.

The project focused on real-world text data, covering the workflow from preprocessing and feature engineering to model comparison and performance analysis.

### 🔧 What I Worked On

- 🧹 Dataset cleaning and preparation
- 📝 Text preprocessing
- 🔢 TF-IDF vectorization
- 🤖 Multiclass classification
- 📊 Model comparison
- 📈 Performance evaluation
- 📦 Exporting the trained model pipeline
- 🚀 API deployment
